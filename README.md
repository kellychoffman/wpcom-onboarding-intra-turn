# WordPress.com onboarding, intra-turn style

A throwaway prototype that reimagines the WordPress.com site-creation flow (`wordpress.com/setup/onboarding`) using the "Feedforward" idea from [Beyond Taking Turns](https://demos.liubruce.me/intra-turn/): the UI shows its plan before you send.

Flow: account, describe the site, review an editable plan (each row tagged as from your words, assumed, or your edit), then a mock build and site preview.

Everything is mocked. Sign-in buttons are fake and the plan comes from simple keyword matching, not a model.

Open `index.html` in a browser. No build step.
